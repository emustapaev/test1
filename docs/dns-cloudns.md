# DNS krunai.uz: что добавить

Документ для владельца домена. Нужно **добавить** несколько записей. Существующие записи (почта Zoho) **менять и удалять нельзя**.

Таблицу с конкретными значениями присылает бот платформы после выкатки. Ниже — что в ней будет и как вносить. Значения в угловых скобках — подставляются из таблицы бота.

## 1. Текущее состояние (не менять)

Снимок публичного DNS: [dns/baseline.txt](dns/baseline.txt) (на 2026-10-23).

| Что | Текущее значение |
|---|---|
| MX | `10 mx.zoho.com.`, `20 mx2.zoho.com.`, `50 mx3.zoho.com.` |
| TXT на основном домене (SPF и проверка Zoho) | `v=spf1 include:zohomail.com ~all`, `zoho-verification=zb69418690.zmverify.zoho.com` |
| DKIM Zoho (селекторы `zmail`, `zoho`, `zmail2`, `zmail3`, `default`) | публично не найдены |
| DMARC (`_dmarc`) | записи нет |

**Важно:** по публичному DNS серверы имён домена сейчас — Cloudflare. Записи нужно вносить в той панели, где управляется зона. Уточните у клиента, где она реально ведётся.

## 2. Записи, которые добавляются

Имя (host) в таблице бота — полное, например `_abc123.krunai.uz`. В панель вводите только часть без `.krunai.uz` и без точки на конце. Для корня домена поле оставляйте пустым. TTL — 3600, если в таблице не указано иное.

| Назначение | Тип | Имя (host) | Значение | Когда |
|---|---|---|---|---|
| Подтверждение SSL-сертификата (ACM), по записи на каждое имя: `krunai.uz` и `www.krunai.uz` | CNAME | `<из таблицы>` | `<из таблицы>.acm-validations.aws` | Сначала |
| Подпись писем (DKIM, Amazon SES), 3 записи | CNAME | `<token>._domainkey` | `<token>.dkim.amazonses.com` | Сначала |
| Обратный адрес писем формы (MAIL FROM), MX | MX | `mail` | `10 feedback-smtp.eu-west-3.amazonses.com` | Сначала |
| Обратный адрес писем формы (MAIL FROM), SPF | TXT | `mail` | `v=spf1 include:amazonses.com ~all` | Сначала |
| Основной адрес сайта | ALIAS | *(пусто)* | `<id>.cloudfront.net` | После включения домена |
| Адрес `www` | CNAME | `www` | `<id>.cloudfront.net` | После включения домена |

Записи MX и TXT для MAIL FROM стоят на поддомене `mail`, а не на основном домене. Они не пересекаются с почтой Zoho.

## 3. Пошагово в панели

1. Откройте зону `krunai.uz` в панели DNS и нажмите добавление записи.
2. Выберите тип из таблицы бота.
3. В поле host вставьте имя без `.krunai.uz`; для корня домена оставьте поле пустым.
4. В поле значения вставьте значение целиком. Для MX приоритет `10`, сервер `feedback-smtp.eu-west-3.amazonses.com`.
5. Сохраните и повторите для каждой строки.
6. Существующие записи не открывайте и не редактируйте.

## 4. Порядок работ

1. Сначала добавьте записи подтверждения (ACM), DKIM и MAIL FROM. Распространение обычно занимает от нескольких минут до получаса.
2. Дождитесь, пока бот подтвердит записи, и включите домен. Платформа сама запускает вторую выкатку. Она дожидается выдачи сертификата и подключает `krunai.uz` и `www` к сайту.
3. Записи сайта (ALIAS на основной домен и CNAME `www`) добавляются по инструкции бота. Если бот их ещё не запросил, сайт на этих адресах может не открываться.

## 5. Если в тарифе нет ALIAS

Основным адресом становится `www.krunai.uz`.

1. Добавьте CNAME `www` → `<id>.cloudfront.net`.
2. Корень домена перенаправьте на `https://www.krunai.uz`: в панели DNS-провайдера откройте перенаправление домена (web redirect), host пустой, тип постоянный (301). Это настройка перенаправления, а не DNS-запись.
3. ALIAS на корень домена не добавляйте. Сообщите платформе, что ALIAS недоступен: канонический хост переключают на `www` (см. [deploy.md](deploy.md), раздел 5).
4. Для HTTPS на корне домена перенаправление может требовать отдельного сертификата. Уточните это в поддержке DNS-провайдера.

## 6. Что не меняется (Zoho и прочее)

Не трогайте:

- MX `mx.zoho.com`, `mx2.zoho.com`, `mx3.zoho.com`;
- TXT на основном домене (SPF `zohomail.com`, `zoho-verification`);
- DKIM Zoho (селекторы `zmail`, `zoho`, `zmail2`, `zmail3`, `default`);
- запись `_dmarc`, если она появится;
- NS и прочие записи, которых нет в таблице бота.

Таблица бота не содержит записей Zoho: все добавляемые записи относятся к `mail`, `www`, корню домена через ALIAS и к именам `_acm` и `_domainkey` SES.

## 7. Проверка

После внесения записей проверьте их в DNS:

```bash
dig +short CNAME <имя>.krunai.uz      # должно вернуть значение из таблицы бота
dig +short MX krunai.uz               # должно остаться как в разделе 1
dig +short TXT krunai.uz              # SPF и zoho-verification без изменений
```

Итоговую проверку (сайт, заявка, письма и заголовки) — в [deploy.md](deploy.md), раздел 7.
