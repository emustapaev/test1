# Дизайн-система KRunAI

Источник токенов — [`design/tokens.css`](../../design/tokens.css) (CSS custom properties с префиксом `--kr-`). Подключается напрямую: `@import "design/tokens.css"` или `<link>`. Название продукта **KRunAI** не переводится ни в одной локали.

Стиль: тёмная технологичная тема с голубым акцентом (ТЗ v1). Подход mobile-first, базовая ширина — 320px.

## 1. Шрифты (кириллица)

| Роль | Шрифт | Лицензия | Кириллица |
|---|---|---|---|
| Заголовки (`--kr-font-heading`) | **Manrope** 600–800 | SIL OFL 1.1 | да |
| Текст, кнопки, формы (`--kr-font-body`) | **Inter** 400–600 | SIL OFL 1.1 | да |

**Обоснование.** Оба шрифта имеют полноценные кириллические глифы (не подмена из запасного шрифта), открытую лицензию, вариативные версии (мало файлов) и хорошо читаются на мелких размерах. Inter нейтрален и разборчив в UI; Manrope придаёт техничный характер заголовкам. Запасной стек — `system-ui`, поэтому при сбое загрузки текст остаётся читаемым.

**Self-hosting.** Внешние CDN (Google Fonts и т. п.) в рантайме не используются. Файлы woff2 лежат в `/fonts/` фронтенда:
`inter-latin.woff2`, `inter-cyrillic.woff2`, `manrope-latin.woff2`, `manrope-cyrillic.woff2` — subsets только latin и cyrillic (диапазоны `unicode-range` заданы в `tokens.css`, браузер скачивает кириллический файл только на RU-странице). `font-display: swap`. Шрифты скачиваются при сборке/разработке из релизов проектов Inter и Manrope (OFL) и кладутся в репозиторий вместе с текстом лицензии. Рекомендуется `<link rel="preload" as="font" type="font/woff2" crossorigin>` для основного файла текущей локали.

## 2. Цвета и контраст (WCAG AA)

| Токен | HEX | Назначение | Контраст на `--kr-color-bg` |
|---|---|---|---|
| `--kr-color-bg` | #0B1020 | фон страницы | — |
| `--kr-color-surface` | #121A30 | карточки, поля | — |
| `--kr-color-text` | #E8ECF6 | основной текст | 16.0:1 (AAA) |
| `--kr-color-text-muted` | #A3AEC8 | второстепенный текст | 8.5:1 (на surface 7.8:1) |
| `--kr-color-primary` | #38BDF8 | акцент, ссылки, кнопки | 8.8:1 |
| `--kr-color-on-primary` | #04121F | текст на акцентной кнопке | 8.8:1 на primary |
| `--kr-color-error` | #FF8A8A | ошибки | 8.3:1 (на surface 7.6:1) |
| `--kr-color-success` | #4ADE80 | успех | 9.9:1 на surface |
| `--kr-color-focus` | #FFD166 | кольцо фокуса | 13.1:1 |
| `--kr-color-border` | #5A6A94 | рамки полей | 3.5:1 (требование для элементов UI ≥ 3:1) |

Все текстовые пары ≥ 4.5:1 (AA для обычного текста), элементы интерфейса ≥ 3:1. Ошибка никогда не передаётся только цветом: рядом всегда есть иконка и текст.

## 3. Типографика

| Токен | Размер (320 → 1440px) | Применение |
|---|---|---|
| `--kr-text-4xl` | 32 → 64px | H1 (hero) |
| `--kr-text-3xl` | 28 → 48px | H2 секций |
| `--kr-text-2xl` | 24 → 36px | H3 |
| `--kr-text-xl` | 20 → 26px | заголовки карточек |
| `--kr-text-lg` | 17 → 20px | лид-абзац |
| `--kr-text-base` | 16px | основной текст |
| `--kr-text-sm` / `xs` | 14 / 13px | подписи, ошибки, footer |

Интерлиньяж: заголовки `--kr-leading-tight` (1.2), текст `--kr-leading-normal` (1.6). Длина строки текста — до `--kr-measure` (68ch). Размер полей ввода не меньше 16px (iOS не увеличивает страницу при фокусе).

## 4. Отступы, радиусы, брейкпоинты

- Отступы — шкала 4px: `--kr-space-1` (4) … `--kr-space-9` (96). Между секциями — `--kr-space-8`/`-9`, внутри карточек — `--kr-space-5`.
- Радиусы: `--kr-radius-sm` 6px (поля, чипы), `-md` 12px (кнопки, карточки), `-lg` 20px (крупные блоки), `-full` (пилюли).
- Брейкпоинты: **320px** (база, min), **768px** (планшет: многоколоночные сетки, горизонтальная навигация), **1440px** (десктоп: контейнер `--kr-container-max` 1200px по центру). В `@media` использовать числа напрямую (`min-width: 768px`) — переменные там не работают.

## 5. Правила для длинных строк (RU длиннее EN на 20–30%)

1. Никаких фиксированных `width`/`height` у кнопок, пунктов меню, табов. Использовать `min-width` + `padding-inline`, высоту задавать через `min-height` (`--kr-tap-target`) и `padding`.
2. Текст в кнопках и ссылках может переноситься: `overflow-wrap: anywhere` для длинных слов, `text-wrap: balance` для заголовков, `text-wrap: pretty` для абзацев. Запрещены `white-space: nowrap`, `text-overflow: ellipsis` и `overflow: hidden` на контейнерах с текстом (исключение — переключатель EN/RU, он состоит из коротких фиксированных меток).
3. Flex/grid-элементы с текстом: `min-width: 0`; сетки — `repeat(auto-fit, minmax(min(100%, 16rem), 1fr))`.
4. На 320px навигация убирается в меню-«бургер»; в шапке остаются логотип, переключатель EN/RU и кнопка меню. CTA «Get started / Начать» переносится в меню или занимает полную ширину под текстом.
5. Заголовки hero на 320px — не более `--kr-text-4xl` (32px) с `hyphens: auto` (в `<html lang="ru">` переносы работают автоматически; всегда задавать `lang`).
6. Проверка: каждый экран открывается на 320px в обеих локалях без горизонтальной прокрутки и обрезки текста; тестовая строка — самое длинное RU-слово интерфейса.

## 6. Компоненты

Общее: фокус — всегда видимое кольцо `box-shadow: var(--kr-focus-ring)` (`:focus-visible`), минимальная область нажатия 44×44px, переходы `--kr-duration-fast`.

### 6.1 Кнопки
- **Primary:** фон `--kr-color-primary`, текст `--kr-color-on-primary`, `font-weight` 600, радиус `-md`, `min-height` 44px, `min-width` 8rem, `padding-inline` `--kr-space-5`. Hover — `primary-hover`; active — `primary-active`; focus-visible — кольцо фокуса; disabled — прозрачность 0.5, `cursor: not-allowed`; loading — спиннер слева, текст остаётся, `aria-busy="true"`.
- **Secondary:** прозрачный фон, рамка 1px `--kr-color-primary`, текст `--kr-color-primary`; hover — фон `surface-raised`.
- Текст может переноситься на 2 строки; кнопка растёт по высоте, на 320px в формах — на всю ширину.

### 6.2 Поля формы
- Структура: видимая `<label>` над полем (не placeholder вместо подписи), поле, подсказка/ошибка под полем.
- Поле: фон `--kr-color-surface`, рамка 1px `--kr-color-border`, радиус `-sm`, `min-height` 44px, текст 16px. Hover — рамка светлее (`text-muted`); focus — рамка `primary` + кольцо фокуса; disabled — приглушено.
- Подпись и подсказка локализованы (EN/RU), перенос разрешён.

### 6.3 Состояния ошибок
- Поле с ошибкой: рамка `--kr-color-error` 2px, иконка «!» внутри/рядом, сообщение под полем цветом `--kr-color-error`, 14px, связано через `aria-describedby`, поле получает `aria-invalid="true"`. Сообщение — `role="alert"` при отправке формы.
- Сообщения строятся из кодов ошибок backend, переводятся на фронтенде (ТЗ v2 §5), поэтому блок под полем растёт по высоте.
- Общая ошибка формы — баннер над кнопкой: фон `surface-raised`, левая полоса `error`, иконка, текст. Успех — аналогично с `--kr-color-success`.

### 6.4 Header и переключатель языка EN/RU
Header закреплён (sticky), высота `--kr-header-height`, фон `--kr-color-bg` с полупрозрачностью и размытием, нижняя граница `border-subtle`. Слева логотип «KRunAI» (не переводится), в центре (от 768px) навигация по якорям (`#how-it-works`, `#benefits`, `#faq`, `#contact`), справа LanguageSwitcher и CTA. До 768px — навигация в бургер-меню, переключатель остаётся видимым в шапке.

**LanguageSwitcher** — `<nav aria-label="Language / Язык">` с двумя ссылками `EN` и `RU` (`<a href="/en/#faq" hreflang="en" lang="en">EN</a>`, `<a href="/ru/#faq" hreflang="ru" lang="ru">RU</a>`). Ссылки ведут на тот же якорь в другой локали; при клике записывается cookie `lang` (ТЗ v2 §3). Оформление — сегментированный контрол: рамка 1px `border`, радиус `-full`, каждый сегмент `min-width` 44px, `min-height` 44px (допустимо визуально 32px при расширенной области нажатия), метки короткие и не переносятся.

| Состояние | Вид |
|---|---|
| Текущая (`aria-current="true"`) | фон `--kr-color-primary`, текст `--kr-color-on-primary`, `font-weight` 600; не кликабельна визуально (`cursor: default`), остаётся ссылкой для скринридера |
| Обычная | прозрачный фон, текст `--kr-color-text-muted` |
| Hover | текст `--kr-color-text`, фон `--kr-color-surface-raised` |
| Focus-visible | кольцо фокуса `--kr-focus-ring` (контур не обрезается — `overflow: visible`) |
| Active | фон `primary-active` / текст `on-primary` |

Состояние «текущая» отличается не только цветом, но и заливкой и жирностью (не опирается на один цвет). Управление с клавиатуры: Tab переходит между ссылками, Enter активирует.

### 6.5 Карточки
Фон `--kr-color-surface`, рамка 1px `border-subtle`, радиус `-lg`, padding `--kr-space-5`, тень `--kr-shadow-card`. Содержимое: иконка, заголовок (`--kr-text-xl`, Manrope), текст. Hover (если карточка интерактивна) — рамка `primary`, подъём 2px. Высота — по содержимому (не фиксируется), сетка `auto-fit`: 1 колонка на 320px, 2–4 с 768px.

### 6.6 Аккордеон FAQ
Список из 5–7 вопросов. Каждый пункт — `<button aria-expanded aria-controls>` внутри заголовка, панель `role="region"` с `aria-labelledby`. Кнопка вопроса: на всю ширину, `min-height` 56px, текст слева с переносом, значок «+/−» справа фиксированного размера (`flex: none`), `padding` `--kr-space-4`. Состояния: закрыт, открыт (значок «−», фон `surface-raised`, панель с ответом), hover (фон `surface-raised`), focus-visible (кольцо фокуса). Enter/Space переключают пункт. Разделитель между пунктами — `border-subtle`. Раскрытие анимируется `--kr-duration-base` (отключается при `prefers-reduced-motion`). Допускается открытие нескольких пунктов одновременно.

## 7. Использование токенов во фронтенде

```css
@import "../../design/tokens.css";
body { background: var(--kr-color-bg); color: var(--kr-color-text); font: var(--kr-text-base)/var(--kr-leading-normal) var(--kr-font-body); }
```
Для Tailwind токены подключаются через `theme.extend` со значениями `var(--kr-…)`. Пути к woff2 в `@font-face` (`/fonts/…`) подстраиваются под каталог статики фронтенда.
